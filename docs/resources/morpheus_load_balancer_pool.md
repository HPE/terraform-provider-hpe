# hpe_morpheus_load_balancer_pool (Resource)

Manages a Morpheus load balancer pool. A pool defines a group of backend servers that receive traffic distributed by a load balancer virtual server.

For NSX-T load balancers, use the `config_nsxt` block to configure SNAT translation, TCP multiplexing, active/passive monitors, and member groups. For other load balancer types, use the generic `config` attribute.

## Example Usage — NSX-T Pool

```terraform
resource "hpe_morpheus_load_balancer_pool" "nsxt" {
  load_balancer_id = 1
  name             = "NSX-T Pool"
  description      = "An NSX-T load balancer pool"
  vip_balance      = "ROUND_ROBIN"
  min_active       = 1

  config_nsxt = {
    snat_translation_type   = "LBSnatAutoMap"
    tcp_multiplexing        = true
    tcp_multiplexing_number = 6
  }
}
```
