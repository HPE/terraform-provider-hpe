# hpe_morpheus_task_write_attributes (Resource)

Provides a Morpheus write attributes task resource

## Example Usage

```terraform
resource "hpe_morpheus_task_write_attributes" "tfexample_write_attributes" {
  name                = "tfexample_write_attributes"
  code                = "tfexample_write_attributes"
  labels              = ["demo", "terraform"]
  attributes          = <<EOF
{"demo":"test"}
EOF
  retryable           = true
  retry_count         = 1
  retry_delay_seconds = 10
  allow_custom_config = true
}
```
