# hpe_opsramp_alert_prediction_policy (Resource)

Manages an OpsRamp Alert Prediction Policy. Uses machine learning to predict future alerts based on historical data.


## Example Usage

```terraform
resource "hpe_opsramp_alert_prediction_policy" "default_alert_prediction_policy" {
  name = "Default Prediction Policy"

  enabled_mode = "OFF"
  filter_query = ""

  seasonality_time_frame    = "7D"
  generate_prediction_alert = true
}
```

## Schema

### Required

- `name` (String) The name of the alert prediction policy.

### Optional

- `client` (String) The client (tenant) UUID where this policy should be created. If not specified, uses the provider's tenant.
- `enabled_mode` (String) The enabled mode of the policy. Valid values: `ON`, `OFF`.
- `filter_query` (String) Filter query to scope which alerts are evaluated by this policy.
- `generate_prediction_alert` (Boolean) Whether to generate predictions based on the policy.
- `seasonality_time_frame` (String) Learning based on the data for last N days. Valid values: `7D`, `10D`, `30D`, `60D`, `90D`.

### Read-Only

- `id` (String) The unique identifier of the alert prediction policy.
