# hpe_morpheus_security_group (Resource)

Manages a Morpheus Security Group resource.

Security groups provide network-level access control for cloud resources. They can be created globally (without a `cloud_id`) to apply across all clouds, or scoped to a specific cloud integration such as Azure or NSX-T.

## Multi-Tenancy and Permissions

Security groups support multi-tenancy and group-based access control:

| Attribute | Description |
|---|---|
| `visibility` | Controls whether the security group is visible to sub-tenants. Set to `"public"` for shared access or `"private"` (default) for owner-only |
| `tenant_ids` | Grants specific tenants access to the security group |
| `resource_permission_groups_all` | When `true`, all groups have access. When `false`, only groups listed in `resource_permission_group_ids` have access |
| `resource_permission_group_ids` | Set of group IDs that have access (only applicable when `resource_permission_groups_all` is `false`) |

## Example Usage

### Basic Security Group

```terraform
resource "hpe_morpheus_security_group" "example" {
  name        = "web-servers"
  description = "Security group for web servers"
  active      = true
}
```

### Azure Security Group

```terraform
data "hpe_morpheus_cloud" "azure" {
  name = "Azure Cloud"
}

data "hpe_morpheus_tenant" "example" {
  name = "Example Tenant"
}

resource "hpe_morpheus_security_group" "azure" {
  name                           = "azure-web-servers"
  description                    = "Security group for Azure web servers"
  cloud_id                       = data.hpe_morpheus_cloud.azure.id
  active                         = true
  visibility                     = "private"
  tenant_ids                     = [data.hpe_morpheus_tenant.example.id]
  resource_permission_groups_all = true
}

resource "hpe_morpheus_security_group_rule" "https" {
  security_group_id = hpe_morpheus_security_group.azure.id
  name              = "Allow HTTPS"
  protocol          = "tcp"
  rule_type         = "customRule"
  direction         = "ingress"
  port_range        = "443"
  source            = "0.0.0.0/0"
  policy            = "accept"
}
```

### NSX-T Security Group

```terraform
data "hpe_morpheus_cloud" "nsxt" {
  name = "NSX-T Cloud"
}

data "hpe_morpheus_group" "example" {
  name = "Example Group"
}

resource "hpe_morpheus_security_group" "nsxt" {
  name                           = "nsxt-app-tier"
  description                    = "Security group for NSX-T application tier"
  cloud_id                       = data.hpe_morpheus_cloud.nsxt.id
  active                         = true
  visibility                     = "public"
  resource_permission_groups_all = false
  resource_permission_group_ids  = [data.hpe_morpheus_group.example.id]
}

resource "hpe_morpheus_security_group_rule" "app_http" {
  security_group_id = hpe_morpheus_security_group.nsxt.id
  name              = "Allow HTTP"
  protocol          = "tcp"
  rule_type         = "customRule"
  direction         = "ingress"
  port_range        = "8080"
  source            = "10.0.0.0/8"
  policy            = "accept"
}
```

## Import

Security groups can be imported using the security group ID, e.g.

```bash
terraform import hpe_morpheus_security_group.example 123
```

## Notes

### Cloud-Scoped Security Groups

When `cloud_id` is set, Morpheus provisions the security group on the cloud provider (e.g., an AWS Security Group or Azure NSG is created via the provider's API). Without `cloud_id`, the security group exists only within Morpheus.

Separately, security groups that already exist on a cloud provider are automatically discovered during cloud inventory sync. The [`default_security_group_sync_active`](https://registry.terraform.io/providers/HPE/hpe/latest/docs/resources/morpheus_cloud) attribute on the `hpe_morpheus_cloud` resource controls whether those discovered security groups are set to active by default.
