# hpe_morpheus_host_power_state (Resource)

Manages the power state of a Morpheus host — turning it `on` or `off` — by host ID. This is a
separate resource from `hpe_morpheus_host` because the party flipping power is often not the owner
of the host: discovered or imported metal, maintenance windows, and lab power-down are all cases
where you want to control power without importing and managing the whole host. Applying this
resource with `power_state = "off"` stops the host; `"on"` starts it. Destroying the resource leaves
the host in its current power state.

## Example Usage

```terraform
resource "hpe_morpheus_host_power_state" "example" {
  host_id     = 123
  power_state = "on"
}
```
