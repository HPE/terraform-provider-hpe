# hpe_morpheus_load_balancer_virtual_server (Resource)

Manages a Morpheus load balancer virtual server (VIP). A virtual server defines a frontend listener on a load balancer, including the VIP address, port, and protocol.

## Example Usage

```terraform
resource "hpe_morpheus_load_balancer_virtual_server" "example" {
  load_balancer_id = 1
  vip_name         = "example-vip"
  description      = "Example virtual server"
  vip_address      = "10.0.0.1"
  vip_port         = 80
  vip_protocol     = "HTTP"
}
```

## Example Usage NSX-T

```terraform
resource "hpe_morpheus_load_balancer_virtual_server" "nsxt" {
  load_balancer_id = 1
  vip_name         = "example-nsxt-vip"
  description      = "Example NSX-T virtual server"
  vip_address      = "10.0.0.2"
  vip_port         = 443
  vip_protocol     = "HTTPS"

  config_nsxt = {
    application_profile = "/infra/lb-app-profiles/default-http-lb-app-profile"
  }
}
```
