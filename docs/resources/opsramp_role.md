# hpe_opsramp_role (Resource)

Manages an OpsRamp Role resource. Roles define access control with permission sets, users, devices, and more.


## Example Usage

```terraform
resource "hpe_opsramp_role" "client_admin_role" {
  name        = "Admin Role"
  description = "Administrative role with full permissions"

  permissions = [
    hpe_opsramp_permission_set.client_admin_perms.unique_id
  ]
}
```

## Schema

### Required

- `name` (String) The name of the role.

### Optional

- `client` (String) The client (tenant) UUID where this role should be created. If not specified, uses the provider's tenant.
- `clients` (Set of String) List of client unique IDs associated with the role.
- `credential_sets` (Set of String) List of credential set unique IDs associated with the role.
- `description` (String) The description of the role.
- `device_groups` (Set of String) List of device group IDs associated with the role.
- `devices` (Set of String) List of device IDs associated with the role.
- `permissions` (Set of String) List of permission set unique IDs assigned to the role.

### Read-Only

- `all_authz_tags` (Boolean) Whether the role applies to all authorization tags. Always true.
- `all_clients` (Boolean) Whether the role applies to all clients. Computed based on whether clients list is empty.
- `all_credentials` (Boolean) Whether the role applies to all credentials. Computed based on whether credential_sets list is empty.
- `all_devices` (Boolean) Whether the role applies to all devices. Computed based on whether devices/device_groups lists are empty.
- `default_role` (Boolean) Whether this is a default role.
- `id` (String) The unique identifier of the role.
- `user_groups` (Set of String) List of user group unique IDs associated with the role. Read-only - manage role assignments via the user_group resource.
- `users` (Set of String) List of user IDs associated with the role. Read-only - manage role assignments via the user resource.
