# hpe_opsramp_integration_event (Resource)

Manages an outbound event on an OpsRamp integration. Events define how OpsRamp notifies external systems when specific entity/event-type combinations occur.


## Example Usage

```terraform
resource "hpe_opsramp_integration_event" "custom_event" {
  integration_id         = hpe_opsramp_integration.custom_bidirectional.id
  name                   = "Custom Event"
  entity                 = "DEFAULT_RESOURCE"
  event_type             = "CREATE"
  resource_group_allowed = false
  use_base_notifier      = true
  endpoint_uri           = "https://external-system.example.com/event-webhook"
  third_party_event_type = "POST"
  event_payload          = "test $default_resource.aliasName"
  headers = {
    "Content-Type" = "application/json"
    "Accept"       = "application/json"
  }
  response_headers = {
    "Status Message" = "$status",
    "extTicketURL"   = "$url",
    "extTicketId"    = "$id",
    "Error Message"  = "$error",
  }
}
```

## Schema

### Required

- `entity` (String) The OpsRamp entity type this event applies to.
- `event_type` (String) The event type that triggers this notification (e.g. `UPDATE`, `CREATE`, `DELETE`).
- `integration_id` (String) The ID of the parent integration (e.g. INTG-...).
- `name` (String) The name of the event.

### Optional

- `active` (Boolean) Whether this event is active.
- `client` (String) The unique ID of the client (sub-tenant). If not provided, uses the provider tenant.
- `custom_attribute_allowed` (Boolean) Whether custom attributes are allowed in the payload.
- `endpoint_uri` (String) The specific endpoint URI for this event (overrides the base URI).
- `event_payload` (String) The payload template to send in the outbound request body.
- `headers` (Map of String) HTTP headers to include in the outbound request (key-value pairs).
- `notifier` (Attributes) Per-event notifier override. Only used when `use_base_notifier` is `false`. (see [below for nested schema](#nestedatt--notifier))
- `resource_group_allowed` (Boolean) Whether resource group context is allowed for this event.
- `response_headers` (Map of String) Headers to extract from the response (key-value pairs). Allowed keys: `Status Message`, `extTicketURL`, `extTicketId`, `Error Message`.
- `third_party_event_type` (String) The HTTP method used to call the external endpoint (e.g. `POST`, `PUT`).
- `use_base_notifier` (Boolean) When `true`, the event uses the integration's base outbound notifier. Set to `false` and provide a `notifier` block to override.

### Read-Only

- `event_level` (String) The scope level of the event (e.g. `client`, `partner`).
- `id` (String) The unique identifier of the event (e.g. INTG-EVENT-...).
