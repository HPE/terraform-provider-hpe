# hpe_morpheus_network_pool (Resource)

Manages a Morpheus Network Pool resource.

## Example Usage

```terraform
resource "hpe_morpheus_network_pool" "example" {
  name           = "App Pool"
  type_code      = "morpheus"
  subnet_address = "10.0.1.0"
  netmask        = "255.255.255.0"
  gateway        = "10.0.1.1"
  dns_domain     = "example.com"

  # Every range of the pool, in the order you want them listed. Each range is
  # edited in place (by its id) when its addresses change.
  ip_address_ranges = [
    {
      starting_address = "10.0.1.10"
      ending_address   = "10.0.1.50"
    },
    {
      starting_address = "10.0.1.100"
      ending_address   = "10.0.1.150"
    },
  ]
}
```

## Ranges

`ip_address_ranges` lists every range of the pool. Morpheus edits a range in place when only its
addresses change (the provider sends the range's `id`), so reservations in the range — including
`hpe_morpheus_network_pool_ip` resources — survive the edit. A range removed from the list is deleted;
Morpheus refuses when the range still has reserved addresses, and the provider reports which range.

### Migrating from `ip_ranges`

`ip_ranges` (a single `{ starting_address, ending_address }` object) is deprecated and is removed in
the 2.6 release. Replace it with the same values inside a one-element `ip_address_ranges` list:

```hcl
# before
ip_ranges = {
  starting_address = "10.0.1.10"
  ending_address   = "10.0.1.50"
}

# after
ip_address_ranges = [
  {
    starting_address = "10.0.1.10"
    ending_address   = "10.0.1.50"
  },
]
```

The plan after the change is empty: `ip_address_ranges` is always read from the appliance, so the
existing range is recognised. A pool that already has several ranges (created in the Morpheus UI, or
by another tool) cannot be managed through `ip_ranges`; the provider refuses the update rather than
delete the other ranges.

## Schema

### Required

- `name` (String) The name of the network pool.
- `type_code` (String) The code of the network pool type. Default available codes are morpheus, morpheusipv6, vcd, and nsx-t. Plugins can add additional pool types.

### Optional

- `dhcp_server` (Boolean) Whether DHCP server is enabled.
- `dns_domain` (String) The DNS domain for the network pool.
- `gateway` (String) The gateway IP address.
- `ip_address_ranges` (Attributes List) The IP address ranges of the pool, in configuration order. Each range is edited in place by its `id`,
so a range's reservations survive a change to its addresses; a range removed from the list is deleted
(Morpheus refuses when it still has reservations). Exactly one of `ip_address_ranges` and the deprecated
`ip_ranges` must be set. (see [below for nested schema](#nestedatt--ip_address_ranges))
- `ip_ranges` (Object, Deprecated) Deprecated: a single IP range as `{ starting_address, ending_address }`. Use `ip_address_ranges`, which
holds every range of the pool. Only one of the two may be set in the configuration. A pool with more
than one range cannot be managed through this attribute. Will be removed in the 2.6 release. (see [below for nested schema](#nestedatt--ip_ranges))
- `netmask` (String) The netmask.
- `subnet_address` (String) The subnet IP address.

### Read-Only

- `free_count` (Number) The number of free IPs in the pool.
- `id` (Number) The ID of the network pool.
- `ip_count` (Number) The total number of IPs in the pool.
- `pool_enabled` (Boolean) Whether the pool is enabled.
