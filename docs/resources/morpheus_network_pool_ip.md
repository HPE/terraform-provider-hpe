# hpe_morpheus_network_pool_ip (Resource)

Manages a Morpheus network pool IP reservation. A reservation claims an address from a network pool for a hostname.

Omit `ip_address` to have the pool allocate its next free address, which is returned as the computed `ip_address`. Supply `ip_address` to pin a specific address, which must lie within the pool's IP ranges. Use `ref_type` and `ref_id` to associate the reservation with a resource such as a server; both can be added or removed after creation. Setting `create_dns` (which requires `domain_id`) creates DNS records for the reservation; both are applied at creation only and changing either replaces the reservation.

## Example Usage

```terraform
# Auto-allocate: omit ip_address and Morpheus reserves the pool's next free
# address, returned as the computed ip_address.
resource "hpe_morpheus_network_pool_ip" "auto" {
  network_pool_id = 1
  hostname        = "host01"
}

# Pinned address: the given ip_address must lie within the pool's IP ranges.
resource "hpe_morpheus_network_pool_ip" "pinned" {
  network_pool_id = 1
  hostname        = "host01-pinned"
  ip_address      = "10.0.0.50"
}

# Attached to a server: associate the reservation with a resource by type/id.
resource "hpe_morpheus_network_pool_ip" "attached" {
  network_pool_id = 1
  hostname        = "host01-attached"
  ref_type        = "ComputeServer"
  ref_id          = 1
}
```

## Import

Network pool IP reservations can be imported using the network pool ID and reservation ID separated by a colon, e.g.

```shell
terraform import hpe_morpheus_network_pool_ip.example <network_pool_id>:<id>
```

Morpheus does not return `domain_id` or `create_dns`, so they are not recoverable on import: an imported reservation has `domain_id` null and `create_dns` false regardless of how it was created. Leave both out of the configuration of an imported reservation and no change is planned. Both are inputs Morpheus accepts only at creation (DNS records are created, or not, when the address is reserved), so setting either on an imported reservation plans a replacement — the address is released and reserved again with records — which is the only way the API can honour the request.
