# hpe_morpheus_network_router (Resource)



## Example Usage

### Dynamic config

```terraform
resource "hpe_morpheus_network_router" "example" {
  name                   = "TestRouter"
  type_id                = 1
  group_id               = 1
  network_integration_id = 1
  enabled                = true

  config = {
    ipManagementType = "dhcpLocal"
  }
}
```


### HPE Morpheus SDN

#### Logical router (`juniperSdnRouter`)

```terraform
# HPE Morpheus SDN logical router (juniperSdnRouter)
#
# Joins SDN virtual networks on an HVM cluster resource pool. The router type
# is selected by the presence of the config_juniper_sdn block; the SDN network
# server is given through network_integration_id.
resource "hpe_morpheus_network_router" "example" {
  name                   = "TestRouter"
  group_id               = 1
  network_integration_id = 1

  config_juniper_sdn = {
    resource_pool_id     = 1
    virtual_network_uids = ["0be6b79b-757c-4d92-affc-8084e328cb4c"]
  }
}
```

#### BGP router (`juniperBGPSdnRouter`)

```terraform
# HPE Morpheus SDN BGP router (juniperBGPSdnRouter)
#
# A BGP peering between the SDN controller and up to four external peers. The
# router type is selected by the presence of the config_juniper_bgp block; the
# SDN network server is given through network_integration_id. The peering's
# MD5 key is write-only (md5_key_wo): it is never stored in state or returned
# by the API, and a change is detected from a digest kept in private state.
resource "hpe_morpheus_network_router" "example" {
  name                   = "TestRouter"
  group_id               = 1
  network_integration_id = 1

  config_juniper_bgp = {
    vendor           = "juniper"
    asn              = 65000
    peer_address_1   = "10.0.0.1"
    address_families = ["inet"]
    hold_time        = 90
  }
}
```

## Import

Network routers can be imported using their ID:

```shell
terraform import hpe_morpheus_network_router.example 42
```

The write-only value `config_juniper_bgp.md5_key_wo` of an HPE Morpheus SDN BGP
router is not stored in state, so the import cannot tell whether the value in your
configuration matches the appliance: it is taken as already applied, the plan
after import is empty, and a later change to it is only detected once the
resource is next updated for another reason (Terraform warns about this on every
plan until then). To have changes detected from the start, append the sha256
digest of the configured key to the import ID:

```shell
terraform import hpe_morpheus_network_router.example "42#config_juniper_bgp.md5_key_wo=<sha256 hex>"
```

The same ID works in an `import` block, where Terraform's `sha256()` function
produces the digest:
`id = "42#config_juniper_bgp.md5_key_wo=${sha256(var.md5_key)}"`.
