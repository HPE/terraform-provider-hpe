# hpe_morpheus_backup_host (Resource)

Manages a Morpheus Backup resource for Hosts.

!> **Warning** Deleting a `hpe_morpheus_backup_host` resource will also delete the Backup Job referenced by `job_id`. Morpheus removes the Backup Job automatically when its last backup is deleted. If that Backup Job is also managed by Terraform (for example via `hpe_morpheus_backup_job`), it will be removed out-of-band and left dangling in your state. After deleting a `hpe_morpheus_backup_host` resource, run `terraform apply -refresh-only` to update the state by removing the deleted Backup Job from the statefile.

## Example Usage

```terraform
resource "hpe_morpheus_backup_host" "example" {
  name                = "Host Backup"
  host_id             = 1
  job_id              = 1
  backup_type_code    = "fileBackup"
  path                = "/etc/hostname"
  storage_provider_id = 1
  enabled             = true
}
```
