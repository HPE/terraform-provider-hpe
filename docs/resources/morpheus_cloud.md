# hpe_morpheus_cloud (Resource)



Clouds are integrations or connections to public, private, hybrid clouds, or bare metal servers. Clouds can belong to many groups and contain many hosts.
HPE Morpheus Enterprise supports most Public Clouds and Private Clouds.

-> A `config_hvm` or `config` block is required. They can be empty.

-> `cloud_type_code` must be set if using a generic `config` block.

## Example Usage (HVM)

```terraform
resource "hpe_morpheus_cloud" "example" {
  name      = "TestCloud"
  tenant_id = 1
  group_id  = 1

  code             = "aCode"
  external_id      = "aCode"
  labels           = ["aLabel1", "aLabel2"]
  data_center_name = "aDatacenter"
  enabled          = true
  location         = "somewhere"
  visibility       = "public"

  agent_install_mode       = "ssh"
  appliance_url            = "https://somewhere.com"
  auto_recover_power_state = true
  import_existing_vms      = "off"

  costing_mode  = "costing"
  guidance_mode = "off"

  security_mode = "off"

  keyboard_layout = "us"

  config_hvm = {
    certificate_provider          = "internal"
    enable_network_type_selection = false
  }
}
```

```bash
terraform import hpe_morpheus_cloud.example 123
```

## Notes

### Agent Installation Modes

- `ssh` The Morpheus agent is installed via SSH connection to the virtual machine.
- `cloudInit` The Morpheus agent is installed using cloud-init during the VM provisioning process. This is the recommended method for most cloud platforms.

### Costing Modes

- `off` No costing functionality enabled.
- `costing` Basic cost tracking enabled.
- `reservations` Cost tracking with reservation support.
- `full` Complete costing functionality with all features enabled.

### Import Existing VMs

- `off` Do not import existing virtual machines.
- `basic` Import existing VMs with basic information only.
- `full` Import existing VMs with complete configuration and metadata.

### Security Modes

- `off` Host firewall is disabled.
- `internal` Host firewall is enabled for internal network protection.

### Resource Dependencies

Before creating a cloud resource, ensure that:

1. The specified `group_id` exists and is accessible.
2. The specified `tenant_id` exists and the user has appropriate permissions.
3. Any referenced certificate providers in `config_hvm.certificate_provider` are properly configured in Morpheus.
