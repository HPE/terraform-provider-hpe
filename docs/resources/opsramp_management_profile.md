# hpe_opsramp_management_profile (Resource)

Manages an OpsRamp Management Profile (Gateway type). Management profiles define the gateway agent configuration used when installing managed resources.


## Example Usage

```terraform
resource "hpe_opsramp_management_profile" "test_profile" {
  name        = "Test Profile"
  description = "Profile for testing integrations"
}
```

## Schema

### Required

- `name` (String) The management profile name.

### Optional

- `client` (String) The client (sub-tenant) UUID where the profile should be created. If omitted, the provider's configured tenant is used.
- `description` (String) Summary describing the management profile.
- `type` (String) The management profile type. Always `Gateway`.

### Read-Only

- `id` (Number) The unique identifier of the management profile assigned by OpsRamp.
- `uuid` (String) The numeric identifier of the management profile assigned by OpsRamp.
