# hpe_morpheus_storage_bucket (Resource)

Manages a Morpheus Storage Bucket resource.

## Example Usage

```terraform
resource "hpe_morpheus_storage_bucket" "example" {
  name          = "Example Storage Bucket"
  provider_type = "s3"
  bucket_name   = "example-bucket"
}
```

### Local storage

A `local` bucket is a directory on the appliance itself, named by `base_path`; it is the
one storage type a fresh appliance can have without any external service, and the one
virtual images fetched by URL need (`default_virtual_image_target`). Local storage is
available to the master tenant only. Morpheus names the bucket `.` itself, so
`bucket_name` is left out; a change to `base_path` is applied in place and does not move
the files already stored under the previous path.

`default_virtual_image_target` is only sent when it is configured. Left out, a bucket keeps
whatever it has, so a bucket that was made the default image store outside Terraform -- or
before this attribute existed -- is not changed by an apply; set it to `false` to take the
default away explicitly.

```terraform
# A bucket on the appliance's own disk: the first bucket a new appliance needs,
# since it ships with none and an image fetched by URL has to land somewhere.
# Local storage is available to the master tenant only; Morpheus names the
# bucket "." itself, so bucket_name is left out.
resource "hpe_morpheus_storage_bucket" "images" {
  name          = "images"
  provider_type = "local"
  base_path     = "/var/opt/morpheus/morpheus-ui/images"

  # Left out, the bucket keeps whatever it has; set it to make this bucket the
  # default image store, or to false to take the default away.
  default_virtual_image_target = true
}
```

## Schema

### Required

- `name` (String) The name of the storage bucket.
- `provider_type` (String) The type of storage bucket (e.g. s3, azure, etc.).

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `access_key` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The access key for the storage bucket.
- `access_key_version` (Number, Deprecated) Deprecated. Changes to access_key are detected automatically; this attribute is no longer needed and will be removed in the 2.6 release.
- `base_path` (String) The directory on the appliance a `local` bucket stores into (Morpheus `config.basePath`).
Required when `provider_type` is `local` and not accepted for any other type. Local storage
is available to the master tenant only. A change is applied in place: Morpheus updates the
record and does not move the files already stored under the previous path.
- `bucket_name` (String) The name of the bucket. Applies to Amazon, Azure, CIFS, NFSv3, Openstack Swift and Rackspace CDN;
Morpheus sets it for `local` (`.`) and, when unset, `nfs` (`/`), so it can be left out for those
and takes the appliance's value.
- `default_backup_target` (Boolean) Whether this is the default backup target.
- `default_virtual_image_target` (Boolean) Whether this is the default store for virtual images Morpheus fetches by URL (the first bucket
an appliance needs: it ships with none). Setting it on one bucket clears it on every other
bucket of the account. Left unset, the bucket keeps whatever it has: a bucket made the default
outside Terraform stays the default. Set it to `false` to take the default away explicitly.
- `endpoint` (String) The endpoint URL for the storage bucket.
- `retention_days` (Number) The number of days to retain files before deletion.
- `secret_key` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The secret key for the storage bucket.
- `secret_key_version` (Number, Deprecated) Deprecated. Changes to secret_key are detected automatically; this attribute is no longer needed and will be removed in the 2.6 release.

### Read-Only

- `id` (Number) The ID of the storage bucket.
- `write_only_revision` (Number) The time, in seconds since the Unix epoch, at which one of the write-only values (access_key, secret_key) was last
sent to Morpheus. Changes whenever one of those values changes; not configurable.

## Import

Import is supported using the resource ID.

```bash
terraform import hpe_morpheus_storage_bucket.example 123
```

The write-only values `access_key`, `secret_key` are not stored in state, so the import
cannot tell whether the values in your configuration match the appliance: they are taken as already
applied, the plan after import is empty, and a later change to them is only detected once the
resource is next updated for another reason (Terraform warns about this on every plan until then).
To have changes detected from the start, append the sha256 digest of each configured write-only
value to the import ID:

```shell
terraform import hpe_morpheus_storage_bucket.example "123#access_key=<sha256 hex>&secret_key=<sha256 hex>"
```

The same ID works in an `import` block, where Terraform's `sha256()` function produces the digest:
`id = "123#access_key=${sha256(var.access_key)}"`.
