# hpe_morpheus_task (Resource)

Tasks are used as components of workflows or units that can be executed directly
on an existing instance.

The `hpe_morpheus_task` resource currently only supports Conditional Workflows, however
other types may be used through the generic config.

## Conditional Workflow Task

```terraform
resource "hpe_morpheus_task" "example_task" {
  name           = "Example Conditional Workflow Task"
  task_type_code = "conditionalWorkflow"
  config_conditional_workflow = {
    conditional_script           = <<-EOT
        if (1 == true) {
            return true;
        }

        return false;
        EOT
    if_operational_workflow_id   = 90
    if_operational_workflow_name = "Test 1"

    else_operational_workflow_id   = 91
    else_operational_workflow_name = "Test 2"
  }

  execute_target = "local"
  retryable      = false
}
```

## Generic Config Task

```terraform
resource "hpe_morpheus_task" "example_task" {
  name           = "Example Generic Task"
  task_type_code = "nestedWorkflow"

  config = {
    operationalWorkflowId   = "90"
    operationalWorkflowName = "Test 1"
  }

  execute_target = "local"
  retryable      = false
}
```
