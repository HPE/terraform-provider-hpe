# hpe_morpheus_cluster_affinity_group_member (Resource)

Places a single compute server in a cluster affinity group, without taking ownership of the group's other members.

~> **Terminology** Morpheus models these as separate things. An **instance** is the
unit you provision and manage. A **compute server** is a machine record backing it, and
may be either a guest virtual machine or a hypervisor host — both appear in the same
collection. A **host** is a compute server that hosts others: it has guests of its own
and no parent. Affinity group members are guests, not the hosts they run on.

-> Use this resource rather than the affinity group's `servers` attribute when anything
else may also add members to the group. The group's membership can only be written as a
whole, so a resource that manages the whole set removes anything it does not list. This
resource manages one membership and leaves the rest alone.

## Example Usage

```terraform
# Place a server in a cluster affinity group without taking ownership of the
# group's other members.
#
# Membership added by other means -- an instance provisioned with
# config_hvm.affinity_group_id, or a node added by hpe_morpheus_instance_node --
# is left untouched.

resource "hpe_morpheus_cluster_affinity_group" "example" {
  cluster_id    = 15056
  name          = "web-tier"
  affinity_type = "KEEP_TOGETHER"
  active        = true
}

resource "hpe_morpheus_cluster_affinity_group_member" "example" {
  cluster_id        = 15056
  affinity_group_id = hpe_morpheus_cluster_affinity_group.example.id
  server_id         = 572308
}
```

## Schema

### Required

- `affinity_group_id` (Number) The affinity group to place the server in.
- `cluster_id` (Number) The cluster the affinity group belongs to.
- `server_id` (Number) The compute server to place in the group. Affinity group members are guests, not the hypervisor hosts they run on.

### Read-Only

- `id` (String) Identifier for this membership, in the form `cluster_id/affinity_group_id/server_id`.

## Import

Import an existing membership using `cluster_id/affinity_group_id/server_id`.

```bash
terraform import hpe_morpheus_cluster_affinity_group_member.example 15056/6221/572308
```

-> A membership has no identifier of its own — it is the pairing that exists, not an
object — so all three parts are required.

~> An instance provisioned with `config_hvm.affinity_group_id` joins the group directly.
That membership is not managed by this resource unless you import it.
