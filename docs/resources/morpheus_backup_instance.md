# hpe_morpheus_backup_instance (Resource)

Manages a Morpheus Backup resource for Instances.

!> **Warning** When a `hpe_morpheus_backup_instance` resource is deleted, Morpheus will also delete its associated Backup Job (referenced by `job_id`) if no other backups are using it. If that Backup Job is also managed by Terraform (e.g.,via `hpe_morpheus_backup_job`), it will be removed outside of Terraform's control, leaving stale state. After destroying a `hpe_morpheus_backup_instance` that is the sole backup on a job, run `terraform apply -refresh-only` to reconcile the state.

## Example Usage

```terraform
resource "hpe_morpheus_backup_instance" "example" {
  name                = "Example Backup"
  instance_id         = 1
  job_id              = 1
  storage_provider_id = 1
  enabled             = true
}
```
