# hpe_morpheus_host_profile (Resource)



Manages a Morpheus HVM host profile — a reusable document of storage (iSCSI, multipath), system (CPU power, logging, timezone) and baseline package settings that can be attached to HVM clusters and hosts to drive compliance.

### Compliance, extraction and remediation

Managing the profile document (this resource) and reading compliance (the `hpe_morpheus_host_profile_compliance` data source) are the Terraform-native, declarative operations. To verify compliance on every plan and apply, wrap the compliance data source in a Terraform `check` block — see the `hpe_morpheus_host_profile_compliance` data source. Extracting a profile from a running host and remediating drift are performed directly in Morpheus; a host profile extracted in Morpheus can then be brought under Terraform management with `terraform import hpe_morpheus_host_profile.<name> <id>`.

## Example Usage

```terraform
resource "hpe_morpheus_host_profile" "example" {
  name        = "Example Host Profile"
  description = "An example host profile"

  config = {
    storage = {
      iscsi = {
        transport    = "tcp"
        chap_enabled = false
      }
      multipath = {
        find_multipaths     = true
        user_friendly_names = true
      }
    }
    system = {
      # config sub-attributes are Optional: one you omit stays null and
      # unmanaged, so Terraform neither sets nor reconciles it. Declare it
      # explicitly (e.g. timezone = "America/Denver") to manage it, and remove
      # it later to clear it.
      cpu = {
        power_management = "performance"
      }
      logging = {
        level = "info"
      }
    }
    baseline = {
      # Extra packages to install, one per line in package=version format.
      additional_packages = "openvswitch=2.17.0"
    }
  }
}
```
