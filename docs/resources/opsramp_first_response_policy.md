# hpe_opsramp_first_response_policy (Resource)

Manages an OpsRamp First Response Policy. Defines automated first response actions for incoming alerts.


## Example Usage

```terraform
resource "hpe_opsramp_first_response_policy" "seasonality_first_response_policy" {
  name = "Seasonal-based Suppression"

  enabled_mode = "OBSERVED"
  filter_query = ""

  pattern_actions = {
    seasonality_time_frame = "7D"
    suppress = {
      seasonal_alerts = true
    }
  }
}
```
