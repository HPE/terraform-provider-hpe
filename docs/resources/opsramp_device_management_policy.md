# hpe_opsramp_device_management_policy (Resource)

Manages an OpsRamp Device Management Policy. Filters resources with rules and assigns monitoring templates, availability rules, credential sets, custom attributes, jobs, and knowledge articles to the matching resources. The policy is automatically run (saved and applied) on create and update.


## Example Usage

```terraform
resource "hpe_opsramp_device_management_policy" "test_policy" {
  name         = "mysql-servers"
  search_query = "name CONTAINS \"mysql\""

  actions = [
    {
      action = "ASSIGN MONITORINGTEMPLATE"
      items = [
        {
          item = "4053"
          parameters = {
            "Packet Count"    = "3"
            "Packet interval" = "1000"
          }
        }
      ]
    },
    {
      action = "Assign Availability Rule"
      items = [
        {
          item = "AND"
        }
      ]
    }
  ]
}
```
