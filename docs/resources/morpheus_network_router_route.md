# hpe_morpheus_network_router_route (Resource)



Used to create and delete Router routes.

~> **Note:** Update is not supported for this resource. Any change to the resource configuration will result in the existing resource being destroyed and a new one being created.

## Example Usage

```terraform
resource "hpe_morpheus_network_router_route" "example" {
  router_id     = 42
  name          = "example-route"
  network       = "10.0.0.0/24"
  next_hop      = "10.0.0.1"
  description   = "Example route"
  mtu           = 1500
  enabled       = true
  default_route = false
}
```
