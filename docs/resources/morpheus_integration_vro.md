# hpe_morpheus_integration_vro (Resource)

Provides a vRealize Orchestrator integration resource

## Example Usage

```terraform
resource "hpe_morpheus_integration_vro" "tf_example_vro_integration" {
  name      = "tfexample vro"
  enabled   = true
  url       = "https://myvro/vco/api"
  username  = "my-vro-username"
  password  = "my-vro-password"
  auth_type = "basic"
  tenant    = "vsphere.local"
  auth_id   = "1"
}
```
