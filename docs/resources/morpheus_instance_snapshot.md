# hpe_morpheus_instance_snapshot (Resource)

Manages an instance snapshot in HPE Morpheus.

~> **Note:** The `retain_on_delete` attribute controls whether the snapshot is
deleted from the Morpheus API when this Terraform resource is destroyed. When
set to `true`, the snapshot persists in Morpheus but is removed from Terraform
state.

## Example Usage

```terraform
resource "hpe_morpheus_instance_snapshot" "example" {
  instance_id      = 1
  name             = "baseline"
  description      = "Golden baseline snapshot"
  memory_snapshot  = false
  retain_on_delete = false
}
```

### Required

- `instance_id` (Number) The ID of the instance to snapshot.
- `name` (String) The name of the snapshot.

### Optional

- `description` (String) A description of the snapshot.
- `for_export` (Boolean) When true, the snapshot is created in an exportable form (a full, standalone disk image) rather than a lightweight in-place snapshot. Supported on MVM/KVM and VMware. Defaults to false.
- `memory_snapshot` (Boolean) Whether to include the instance's memory in the snapshot.
- `retain_on_delete` (Boolean) When true, the snapshot is left in Morpheus when the resource is destroyed (removed from Terraform state only). Defaults to false.

## Import

Import is supported using the composite format `<instance_id>/<snapshot_id>`:

```shell
# Import format: <instance_id>/<snapshot_id>
terraform import hpe_morpheus_instance_snapshot.example 123/456
```

return a reference to the parent instance.
