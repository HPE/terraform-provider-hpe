# hpe_opsramp_custom_integration (Resource)

Manages an OpsRamp Custom Integration resource. This resource creates an API OAuth2 token for integrations.


## Example Usage

```terraform
resource "hpe_opsramp_custom_integration" "example_custom_api_integration" {
  display_name = "Example Custom Integration"
  role_name    = "Custom Integration Role"
}
```

## Schema

### Required

- `display_name` (String) The display name of the custom integration.
- `role_name` (String) The name of the role to assign to the integration. This determines the permissions for the API token.

### Optional

- `client` (String) The unique ID of the client (sub-tenant) where the integration should be created. If not provided, the integration is created at the partner (provider tenant) level.

### Read-Only

- `api_client_id` (String, Sensitive) The OAuth2 client ID generated for this integration. Use this for API authentication.
- `api_client_secret` (String, Sensitive) The OAuth2 client secret generated for this integration. Use this for API authentication.
- `id` (String) The unique identifier of the custom integration.
