# hpe_morpheus_image (Data Source)



Image datasource provides information about Morpheus images which may be used
during instance provisioning.

## Example Usage

Get an `image` by `id`
```terraform
data "hpe_morpheus_image" "test" {
  id = 99
}
```

Get an `image` by `name`
```terraform
data "hpe_morpheus_image" "test" {
  name = "Example name"
}
```

Get an `image` by `name` and `image_type`, this option can be useful when there are multiple
images with the same name.
```terraform
data "hpe_morpheus_image" "test" {
  name = "Example name"
  image_type = "qcow2"
}
```
