# hpe_morpheus_instance (Data Source)



Instance is a virtual machine or container deployed and managed by HPE Morpheus.
Morpheus oversees its entire lifecycle, from initial provisioning to scaling, 
monitoring, and eventual decommissioning.

The datasource aims to closely match the API response and include as much
information about the instance as possible. While the schema should match the API
response closely some fields have been renamed, please reference the field names
below.

## Example Usage

Get an `instance` by `id`
```terraform
data "hpe_morpheus_instance" "example" {
    id = 99
}
```

Get an `instance` by `name`
```terraform
data "hpe_morpheus_instance" "example" {
    name = "HVM Instance"
}
```
