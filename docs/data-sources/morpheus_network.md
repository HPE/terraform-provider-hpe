# hpe_morpheus_network (Data Source)



## Example Usage

```terraform
data "hpe_morpheus_network" "example" {
  id = 99
}
```

```terraform
data "hpe_morpheus_network" "example" {
  name = "Example name"
}
```

### One network, several clouds

Morpheus keeps a network record **per cloud**. When more than one cloud covers the
same account — a cloud scoped to one Azure resource group or AWS region alongside
one covering the whole subscription or all regions, or a vSphere cloud alongside
the NSX-T cloud for the same vCenter — every cloud discovers the network on its
next refresh (every 5 minutes by default) and keeps its own record of it, under
the same name. A lookup by `name` alone then finds one record per cloud and
fails; set `cloud_id` to select the cloud whose record you want — normally the
cloud the network is managed through. Amazon subnets are also renamed by the sync
(to `<cidr> (<subnet id>)`), so look those up by `id` or through the renamed name.

The other clouds' records are Morpheus's own view of the same physical network:
they appear after the network is created and disappear on the refresh after it is
destroyed. Do not delete them to tidy up — deleting a record deletes the network
in the cloud, whichever cloud's record it is.

```terraform
# A network that two clouds see — here a cloud scoped to one resource group and
# a second cloud covering the whole subscription — has a record in each, under
# the same name. cloud_id selects the record of the cloud you manage it through.
data "hpe_morpheus_cloud" "scoped" {
  name = "Azure Cloud"
}

data "hpe_morpheus_network" "example" {
  name     = "Example name"
  cloud_id = data.hpe_morpheus_cloud.scoped.id
}
```

## Schema

### Optional

- `cloud_id` (Number) Cloud (zone) the network belongs to. Morpheus keeps one network record per cloud, so when two clouds cover the same account — one scoped to a resource group or region and one to the whole account, say — a network exists as a separate record in each, under the same name, and a lookup by `name` alone finds both. Set `cloud_id` to select the record of one cloud; with `id`, the network must belong to that cloud. Always returned.
- `id` (Number) Morpheus ID of the network being referenced
- `name` (String) The name of the Morpheus network. Must not be empty. Names are unique within a cloud, not across clouds; see `cloud_id`.

### Read-Only

- `cidr` (String) Network CIDR

- `display_name` (String) Network Display Name
