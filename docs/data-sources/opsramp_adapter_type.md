# hpe_opsramp_adapter_type (Data Source)

Looks up an OpsRamp monitoring adapter type by exact name. Use the `name` value as the `application_type` on a `hpe_opsramp_template` metric group whose `adapter_type` is `APPLICATION`.

## Example Usage

```terraform
data "hpe_opsramp_adapter_type" "rse" {
  name = "RSE"
}
```
