# hpe_morpheus_network_proxy (Data Source)

Retrieves the id of a Morpheus network proxy by name or id, for use with `network_proxy_id` on `hpe_morpheus_network`.

## Example Usage

```terraform
data "hpe_morpheus_network_proxy" "example" {
  id = 99
}
```

```terraform
data "hpe_morpheus_network_proxy" "example" {
  name = "Example name"
}
```

## Migrating from hpegl

This data source is the hpe equivalent of `hpegl_vmaas_network_proxy`. It resolves a
network proxy id, which is consumed by `network_proxy_id` on `hpe_morpheus_network`.

```hcl
# hpegl
data "hpegl_vmaas_network_proxy" "example" {
  name = "example-proxy"
}

# hpe
data "hpe_morpheus_network_proxy" "example" {
  name = "example-proxy"
}
```
