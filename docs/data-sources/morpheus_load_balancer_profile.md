# hpe_morpheus_load_balancer_profile (Data Source)

Reads a Morpheus load balancer profile. This data source can be used to look up an existing profile by ID or name to reference its attributes in other resources.

For NSX-T load balancers, the typed configuration blocks (`config_http`, `config_fast_tcp`, `config_fast_udp`, `config_cookie_persistence`, `config_source_ip_persistence`, `config_generic_persistence`, `config_client_ssl`, `config_server_ssl`) are automatically populated based on the profile's service type.

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_load_balancer_profile" "example" {
  load_balancer_id = 1
  id               = 99
}
```

### Look up by Name

```terraform
data "hpe_morpheus_load_balancer_profile" "example" {
  load_balancer_id = 1
  name             = "My Profile"
}
```
