# hpe_morpheus_backup_instance (Data Source)

Reads a Morpheus Instance Backup resource by its ID or name.

An instance backup is a typed projection of the underlying backup object, exposing instance-specific fields (the associated instance, container, etc.).

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_backup_instance" "example" {
  id = 99
}
```

### Look up by Name

```terraform
data "hpe_morpheus_backup_instance" "example" {
  name = "Example Instance Backup"
}
```
