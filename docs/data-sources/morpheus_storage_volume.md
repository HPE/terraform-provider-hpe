# hpe_morpheus_storage_volume (Data Source)

Retrieves information about a single Morpheus storage volume by id or name.

~> **Note** Storage volume names are not guaranteed to be unique. When looking
up by `name`, this data source returns an error (`multiple storage volumes were
returned`) if more than one storage volume matches. To retrieve one or more
storage volumes by name without this restriction, use the
`hpe_morpheus_storage_volumes` (plural) data source with a `filter` block.

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_storage_volume" "example" {
  id = 99
}
```

### Look up by Name

```terraform
data "hpe_morpheus_storage_volume" "example" {
  name = "Example name"
}
```
