# hpe_morpheus_cloud_affinity_group (Data Source)



-> Unlike the [`hpe_morpheus_cloud_affinity_group`](https://registry.terraform.io/providers/HPE/hpe/latest/docs/resources/morpheus_cloud_affinity_group) resource, this data source also returns affinity groups that Morpheus imported from vCenter DRS rules on a VMware cloud. Check `source` to tell a group created by a user (`"user"`) from an imported one (`"sync"`). This data source is the supported way to reference an imported group.

-> Note that Morpheus version `8.0.10` or later is required for affinity group support.

## Example Usage - Name

```terraform
data "hpe_morpheus_cloud_affinity_group" "example" {
  name     = "default"
  cloud_id = 1
}
```

## Example Usage - Id

```terraform
data "hpe_morpheus_cloud_affinity_group" "example" {
  id       = 1
  cloud_id = 1
}
```
