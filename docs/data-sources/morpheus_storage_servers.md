# hpe_morpheus_storage_servers (Data Source)

Retrieves a list of Morpheus storage servers, optionally filtered using one or more filter blocks.

## Example Usage

```terraform
# Filter by name. Values are Go regular expressions; a storage server matches
# the block if its name matches ANY value.
data "hpe_morpheus_storage_servers" "by_name" {
  filter {
    name   = "name"
    values = ["^prod-", "-alletra$"]
  }
}

# Filter by storage server type code (for example, 3par or hpealletramp-storage-provider).
data "hpe_morpheus_storage_servers" "three_par" {
  filter {
    name   = "type_code"
    values = ["3par"]
  }
}

# Filter by the cloud (zone) the storage server is scoped to, by name or id.
data "hpe_morpheus_storage_servers" "by_cloud" {
  filter {
    name   = "cloud_name"
    values = ["Production"]
  }
}

# Multiple filter blocks are ANDed together.
data "hpe_morpheus_storage_servers" "enabled_three_par" {
  filter {
    name   = "type_code"
    values = ["3par"]
  }

  filter {
    name   = "enabled"
    values = ["true"]
  }
}

# No filter blocks returns all storage servers (up to 250).
data "hpe_morpheus_storage_servers" "all" {}

# Consume the full objects returned in `storage_servers`.
output "storage_server_ids" {
  value = [for s in data.hpe_morpheus_storage_servers.by_name.storage_servers : s.id]
}
```

## Supported `filter` keys

Each `filter` block sets `name` to one of the keys below and `values` to one or
more Go regular expressions. A storage server matches a block when the key's
value matches **any** of the supplied `values`; multiple `filter` blocks are
**ANDed** together.

| Key | Matches |
|-----|---------|
| `name` | The storage server name. |
| `type_id` | The storage server type id. |
| `type_code` | The storage server type code (for example, `3par` or `hpealletramp-storage-provider`). |
| `cloud_id` | The cloud (zone) id, when the server is scoped to a `ComputeZone`. |
| `cloud_name` | The cloud (zone) name, when the server is scoped to a `ComputeZone`. |
| `visibility` | The visibility, `public` or `private`. |
| `enabled` | Whether the server is enabled, `true` or `false`. |
| `status` | The storage server status. |

Common `type_code` values: `nfs`, `3par` (HPE 3PAR / Primera), `isilon`, `ecs`,
`hpealletramp-storage-provider` (HPE Alletra MP and Alletra 9000 9060/9080), and
`hpealletramp-X10000-provider.storage` (HPE Alletra MP X10000). Run with no
filter blocks and inspect `storage_servers[*].type_code` to discover the values
present in your environment.
