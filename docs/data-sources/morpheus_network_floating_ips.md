# hpe_morpheus_network_floating_ips (Data Source)

Lists Morpheus network floating IPs, optionally filtered by cloud, server, status or search phrase.

-> The `cloud_id`, `server_id`, `ip_status` and `phrase` arguments are applied server-side as query filters. The `filter` block applies additional client-side filtering (Go regular expressions) over the returned results.

## Example Usage

```terraform
data "hpe_morpheus_network_floating_ips" "example" {
  ip_status = "assigned"

  filter {
    name   = "cloud_name"
    values = ["prod-.*"]
  }
}
```
