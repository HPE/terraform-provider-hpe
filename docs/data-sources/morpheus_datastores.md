# hpe_morpheus_datastores (Data Source)

Retrieves a list of Morpheus datastores, optionally filtered using one or more filter blocks.

## Example Usage

```terraform
# List all datastores.
data "hpe_morpheus_datastores" "all" {}

# List only NFS datastores.
data "hpe_morpheus_datastores" "nfs_only" {
  filter {
    name   = "type"
    values = ["nfs"]
  }
}

# Combine filters (AND logic): NFS datastores that are provisioned.
data "hpe_morpheus_datastores" "nfs_provisioned" {
  filter {
    name   = "type"
    values = ["nfs"]
  }
  filter {
    name   = "status"
    values = ["provisioned"]
  }
}
```

## Supported `filter` keys

Each `filter` block sets `name` to one of the keys below and `values` to one or
more Go regular expressions. A datastore matches a block when the key's value
matches **any** of the supplied `values`; multiple `filter` blocks are **ANDed**
together.

| Key | Matches |
|-----|---------|
| `name` | The datastore name. |
| `code` | The datastore code. |
| `type` | The underlying type (e.g. `nfs`, `vmfs`, `generic`, `cluster`). |
| `status` | The datastore status (e.g. `provisioned`, `failed`, `warning`). |
| `visibility` | The visibility, `public` or `private`. |
| `associated_resource_type` | The associated resource type, either `Cloud` or `Cluster`. |
