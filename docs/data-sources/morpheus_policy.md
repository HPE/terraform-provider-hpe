# hpe_morpheus_policy (Data Source)



Policies are different rules that can be applied to various Morpheus resources.
The policy datasource provides information on existing policies such as their associated
resource type and id and their configuration (which is provided as both a dynamic and static schema).

## Example Usage

Get a `policy` by `id`
```terraform
data "hpe_morpheus_policy" "test" {
  id = 99
}
```

Get a `policy` by `name`
```terraform
data "hpe_morpheus_policy" "test" {
  name = "Example name"
}
```
