# hpe_morpheus_datastore_types (Data Source)

Retrieves a list of Morpheus datastore types, optionally filtered using one or more filter blocks.

## Example Usage

```terraform
# List all datastore types.
data "hpe_morpheus_datastore_types" "all" {}

# Filter datastore types by code.
data "hpe_morpheus_datastore_types" "alletra" {
  filter {
    name   = "code"
    values = ["hpedatastore-alletra-mp-bmaas"]
  }
}

# Filter datastore types that are creatable.
data "hpe_morpheus_datastore_types" "creatable" {
  filter {
    name   = "creatable"
    values = ["true"]
  }
}
```

## Supported `filter` keys

Each `filter` block sets `name` to one of the keys below and `values` to one or
more Go regular expressions. A datastore type matches a block when the key's
value matches **any** of the supplied `values`; multiple `filter` blocks are
**ANDed** together.

| Key | Matches |
|-----|---------|
| `name` | The datastore type name. |
| `code` | The datastore type code. |
| `external_type` | The external type identifier. |
| `disk_type` | The disk type (e.g. `ssd`, `hdd`). |
| `creatable` | Whether the datastore type is creatable, `true` or `false`. |
| `is_plugin` | Whether the datastore type is a plugin, `true` or `false`. |
