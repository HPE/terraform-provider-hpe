# hpe_morpheus_instance_layout (Data Source)



`hpe_morpheus_instance_layout` data source ....

Instance layouts are attached to instance types. An instance layout can only be attached to a single instance type and a single technology. An instance type can have one or many instance layouts attached to it, allowing for a single instance type to work with any technology type. Node types are added to instance layouts. An instance layout can have one or many node types attached to it. Node types can be shared across instance layouts of matching technology types.
