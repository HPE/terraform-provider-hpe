# hpe_morpheus_storage_server (Data Source)

Retrieves information about a single Morpheus storage server by id or name.

~> **Note** Storage server names are not guaranteed to be unique. When looking
up by `name`, this data source returns an error (`multiple storage servers were
returned`) if more than one storage server matches. To retrieve one or more
storage servers by name without this restriction, use the
`hpe_morpheus_storage_servers` (plural) data source with a `filter` block.

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_storage_server" "example" {
  id = 99
}
```

### Look up by Name

```terraform
data "hpe_morpheus_storage_server" "example" {
  name = "Example name"
}
```
