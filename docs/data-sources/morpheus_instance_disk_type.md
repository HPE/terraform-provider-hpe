# hpe_morpheus_instance_disk_type (Data Source)

Looks up a Morpheus instance disk type (storage volume type) by name within a cloud, layout and group, returning its `id` for use as `storage_type_id` on `hpe_morpheus_instance` volumes.

## Example Usage

```terraform
data "hpe_morpheus_cloud" "example" {
  name = "hvm"
}

data "hpe_morpheus_instance_disk_type" "example" {
  name      = "Standard"
  cloud_id  = data.hpe_morpheus_cloud.example.id
  layout_id = 77
  group_id  = 1
}
```

## Migrating from hpegl

This data source is the hpe equivalent of `hpegl_vmaas_instance_disk_type`. Both resolve a
disk type (Morpheus "storage volume type") by name within a cloud, layout and group, and
return its `id` for use as `storage_type_id` on `hpe_morpheus_instance` volumes. The cloud,
layout and group ids that hpegl takes as strings are `int64` here, so they compose directly
with other hpe data sources.

```hcl
# hpegl
data "hpegl_vmaas_instance_disk_type" "std" {
  name      = "Standard"
  cloud_id  = data.hpegl_vmaas_cloud.cloud.id
  layout_id = data.hpegl_vmaas_layout.layout.id
  group_id  = data.hpegl_vmaas_group.group.id
}

# hpe
data "hpe_morpheus_instance_disk_type" "std" {
  name      = "Standard"
  cloud_id  = data.hpe_morpheus_cloud.cloud.id
  layout_id = data.hpe_morpheus_instance_type_layout.layout.id
  group_id  = data.hpe_morpheus_group.group.id
}

resource "hpe_morpheus_instance" "example" {
  volumes = [{
    storage_type_id = data.hpe_morpheus_instance_disk_type.std.id
  }]
}
```

## Schema

### Required

- `cloud_id` (Number) The ID of the cloud (zone) to scope the disk type lookup.
- `group_id` (Number) The ID of the group (site) to scope the disk type lookup.
- `layout_id` (Number) The ID of the instance layout to scope the disk type lookup.
- `name` (String) The name of the disk type (storage volume type) to look up (for example "Standard"). Matched case-insensitively and whitespace-trimmed.

### Read-Only

- `code` (String) The code of the disk type.
- `default_type` (Boolean) Whether this is the default disk type.
- `display_name` (String) The display name of the disk type.
- `display_order` (Number) The display order of the disk type in the Morpheus UI.
- `enabled` (Boolean) Whether the disk type is enabled.
- `id` (Number) The ID of the disk type. Use this as storage_type_id on hpe_morpheus_instance volumes.
- `volume_category` (String) The volume category of the disk type (for example "disk").
