# hpe_opsramp_device_management_policy (Data Source)

Looks up an OpsRamp Device Management Policy by exact name and returns its identifiers and summary attributes.

## Example Usage

```terraform
data "hpe_opsramp_device_management_policy" "test_policy" {
  name = "mysql-servers"
}

output "device_management_policy_id" {
  value = data.hpe_opsramp_device_management_policy.test_policy.id
}
```

## Schema

### Required

- `name` (String) The device management policy name to look up.

### Optional

- `client` (String) Optional client (tenant) UUID to query against. Defaults to the provider tenant.

### Read-Only

- `customized` (Boolean) Whether this policy has been customized (cloned) from a parent policy.
- `execution_order` (Number) The execution order of the policy.
- `global_policy` (Boolean) Whether this is a global policy rather than a tenant-specific policy.
- `id` (Number) The numeric identifier of the policy.
- `match_type` (String) How the policy's filter rules are combined (`ALL` or `ANY`).
- `parent_policy` (Number) The numeric `id` of the parent policy to clone this policy from.
- `parent_policy_uid` (String) The `uid` of the parent policy, when this policy was cloned.
- `resource_type` (String) The type of resource the policy applies to.
- `uid` (String) The unique identifier (e.g. `POLICY-xxxxxxxx`) of the policy, usable with `hpe_opsramp_device_management_policy` import.
