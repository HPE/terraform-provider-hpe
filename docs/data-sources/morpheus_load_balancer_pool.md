# hpe_morpheus_load_balancer_pool (Data Source)

Reads a Morpheus load balancer pool. This data source can be used to look up an existing pool by ID or name to reference its attributes in other resources.

For NSX-T load balancers, the `config_nsxt` attribute is automatically populated with the typed configuration. For other load balancer types, the raw configuration is available in the `config` attribute.

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_load_balancer_pool" "example" {
  load_balancer_id = 1
  id               = 99
}
```

### Look up by Name

```terraform
data "hpe_morpheus_load_balancer_pool" "example" {
  load_balancer_id = 1
  name             = "My Pool"
}
```
