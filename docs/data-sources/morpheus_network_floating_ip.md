# hpe_morpheus_network_floating_ip (Data Source)

Looks up a single Morpheus network floating IP by id or by IP address.

-> Supply exactly one of `id` or `ip_address`. Lookup by `ip_address` uses the list endpoint and requires the address to match a single floating IP.

## Example Usage

```terraform
data "hpe_morpheus_network_floating_ip" "example" {
  id = 99
}
```

```terraform
data "hpe_morpheus_network_floating_ip" "example" {
  ip_address = "10.0.0.5"
}
```

## Schema

### Optional

- `id` (Number) The ID of the network floating IP. Conflicts with `ip_address`.
- `ip_address` (String) The IP address of the network floating IP. Conflicts with `id`.

### Read-Only

- `cloud_id` (Number) The ID of the cloud the floating IP belongs to.
- `cloud_name` (String) The name of the cloud the floating IP belongs to.
- `date_created` (String) When the floating IP was created.
- `external_id` (String) The external ID of the floating IP.
- `ip_range_end_address` (String) The end address of the pool range the floating IP was allocated from.
- `ip_range_start_address` (String) The start address of the pool range the floating IP was allocated from.
- `ip_status` (String) The status of the floating IP, one of `assigned`, `free` or `pending`.
- `last_updated` (String) When the floating IP was last updated.
- `network_domain_id` (Number) The ID of the network domain the floating IP belongs to, if any.
- `network_domain_name` (String) The name of the network domain the floating IP belongs to, if any.
- `ptr_id` (String) The PTR record ID of the floating IP.
- `server_id` (Number) The ID of the server (VM) the floating IP is attached to, if any.
- `server_name` (String) The name of the server (VM) the floating IP is attached to, if any.
