# hpe_morpheus_network_interface_type (Data Source)

Retrieves the id of a Morpheus network interface (NIC) type available for a given cloud and provision type, for use with `network_type_id` on `hpe_morpheus_instance` or `network_interface_type_id` on `hpe_morpheus_instance_clone`.

## Example Usage

```terraform
data "hpe_morpheus_network_interface_type" "example" {
  name     = "VMXNET 3"
  cloud_id = 1
}
```

## Migrating from hpegl

This data source is the hpe equivalent of `hpegl_vmaas_network_interface`. It resolves a
network interface (NIC) type id, which is consumed by `network_type_id` on
`hpe_morpheus_instance` and `network_interface_type_id` on `hpe_morpheus_instance_clone`.

hpegl hardcodes the VMware provision type; hpe exposes `provision_type_code` (defaulting
to `vmware`) so non-VMware clouds remain reachable.

```hcl
# hpegl
data "hpegl_vmaas_network_interface" "example" {
  name = "VMXNET 3"
}

# hpe
data "hpe_morpheus_network_interface_type" "example" {
  name     = "VMXNET 3"
  cloud_id = 1
}
```

## Schema

### Required

- `cloud_id` (Number) The id of the cloud (zone) the network interface type is available in.
- `name` (String) The name of the network interface type to look up (for example `E1000` or `VMXNET 3`).

### Optional

- `provision_type_code` (String) The provision type code the network interface type belongs to. Defaults to `vmware`.

### Read-Only

- `code` (String) The code of the network interface type.
- `id` (Number) The id of the network interface type.
