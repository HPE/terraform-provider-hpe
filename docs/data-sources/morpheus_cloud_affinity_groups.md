# hpe_morpheus_cloud_affinity_groups (Data Source)



-> Unlike the [`hpe_morpheus_cloud_affinity_group`](https://registry.terraform.io/providers/HPE/hpe/latest/docs/resources/morpheus_cloud_affinity_group) resource, this data source also returns affinity groups that Morpheus imported from vCenter DRS rules on a VMware cloud. Check each entry's `source` to tell a group created by a user (`"user"`) from an imported one (`"sync"`), or narrow the results with a `filter` block on `source`. This data source is the supported way to reference an imported group.

-> Note that Morpheus version `8.0.10` or later is required for affinity group support.

## Example Usage

```terraform
data "hpe_morpheus_cloud_affinity_groups" "example" {
  cloud_id = 1

  filter {
    name   = "affinity_type"
    values = ["KEEP_TOGETHER"]
  }
}
```
