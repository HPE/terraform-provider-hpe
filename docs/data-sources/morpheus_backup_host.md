# hpe_morpheus_backup_host (Data Source)

Reads a Morpheus Host Backup resource by its ID or name.

A host backup is a typed projection of the underlying backup object, exposing host-specific fields (the associated server, target path, etc.).

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_backup_host" "example" {
  id = 99
}
```

### Look up by Name

```terraform
data "hpe_morpheus_backup_host" "example" {
  name = "Example Host Backup"
}
```
