# hpe_morpheus_host (Data Source)



~> **Terminology** A **host** is a compute server that hosts others — a hypervisor,
bare-metal server, or Kubernetes node — with no parent of its own. Look a host up by
`id`, or by `name` together with an optional `cloud_id` to disambiguate. `bare_metal` is
derived from the compute server type.

-> This data source reads hosts of **every** type, including ones the `hpe_morpheus_host` resource
cannot create: HVM hypervisors (`mvm`) are created by `hpe_morpheus_cluster`, and virtual machines by
`hpe_morpheus_instance`. See the resource's documentation for which types are creatable.

## Example Usage

```terraform
data "hpe_morpheus_host" "example" {
  id = 1
}
```

```terraform
data "hpe_morpheus_host" "example" {
  name     = "Example host"
  cloud_id = 17
}
```

## Schema

### Optional

- `cloud_id` (Number) The ID of the cloud this host belongs to. With name, scopes the lookup to that cloud (hosts with the same name in different clouds).
- `id` (Number) The ID of the host. Conflicts with name.
- `name` (String) The name of the host. Conflicts with id.
