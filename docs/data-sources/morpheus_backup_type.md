# hpe_morpheus_backup_type (Data Source)

Reads a Morpheus backup type by its ID or name. Backup types define the kind of
backup that can be performed (for example snapshot, file backup, or database
backup) and the restore capabilities each one supports.

Exactly one of `id` or `name` must be specified.

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_backup_type" "example" {
  id = 1
}
```

### Look up by Name

```terraform
data "hpe_morpheus_backup_type" "example" {
  name = "File Backup"
}
```
