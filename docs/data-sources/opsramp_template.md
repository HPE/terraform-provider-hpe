# hpe_opsramp_template (Data Source)

Looks up an OpsRamp monitoring template by exact name and returns its identifiers and summary attributes.

## Example Usage

```terraform
data "hpe_opsramp_template" "example" {
  name  = "Active Directory Performance Counters DotNet v4"
  scope = "GLOBAL"
}

output "template_id" {
  value = data.hpe_opsramp_template.example.id
}
```

## Schema

### Required

- `name` (String) The template name to look up.

### Optional

- `client` (String) Optional client (tenant) UUID to query against. Defaults to the provider tenant.
- `scope` (String) Template scope to search within. Valid values: `GLOBAL`, `SERVICE PROVIDER`, `PARTNER`, `CLIENT`. Defaults to `CLIENT`.

### Read-Only

- `collector_type` (String) The collector type (e.g. `OpsRamp Agent`, `OpsRamp Gateway`).
- `description` (String) A description of the template.
- `generation` (Number) The template generation (`1` or `2`).
- `id` (String) The unique identifier (UUID) of the template, usable with `hpe_opsramp_template` import.
- `resource_type` (String) The resource type this template applies to.
- `status` (String) The template activity status (e.g. `ACTIVE`).
- `tags` (String) Tag(s) associated with the template.
