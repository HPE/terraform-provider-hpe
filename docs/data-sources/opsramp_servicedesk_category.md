# hpe_opsramp_servicedesk_category (Data Source)

Looks up an OpsRamp service desk category by name and returns its string ID. An optional client and ticket_type can be supplied to narrow the lookup.

## Example Usage

```terraform
data "hpe_opsramp_servicedesk_category" "default_category" {
  name = "Service"
}
```

## Schema

### Required

- `name` (String) The exact category name to look up.

### Optional

- `client` (String) Optional client (tenant) UUID to query against. Defaults to the provider tenant.
- `ticket_type` (String) Optional ticket type to disambiguate category lookup. Accepts values like `incidents`, `problems`, or `serviceRequests`.

### Read-Only

- `id` (String) The string ID of the matching category.
