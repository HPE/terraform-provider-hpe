# hpe_morpheus_network_pool_ip (Data Source)

Reads a single IP address reservation (host record) from a Morpheus network pool, by id, by address or by hostname.

## Example Usage

```terraform
data "hpe_morpheus_network_pool_ip" "example" {
  network_pool_id = 99
  id              = 1
}
```

```terraform
data "hpe_morpheus_network_pool_ip" "example" {
  network_pool_id = 99
  ip_address      = "10.0.0.5"
}
```
