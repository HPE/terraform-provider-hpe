# hpe_morpheus_hosts (Data Source)



~> **Hosts vs compute servers** This data source is a host-focused view over the same
`/api/servers` collection as `hpe_morpheus_compute_servers`, which stays available. It
filters only on host-relevant keys. `cloud_id`, `group_id`, `bare_metal` and `phrase` are
query parameters of the list; `compute_server_type` (type code) is applied client-side. Whether a
host is bare metal comes from the server types list (`/api/server-types`), since the servers API
does not render the flag.

-> This data source reads hosts of **every** type, including ones the `hpe_morpheus_host` resource
cannot create: HVM hypervisors (`mvm`) are created by `hpe_morpheus_cluster`, and virtual machines by
`hpe_morpheus_instance`. See the resource's documentation for which types are creatable.

## Example Usage

```terraform
data "hpe_morpheus_hosts" "example" {
  cloud_id   = 17
  bare_metal = false
}
```

## Schema

### Optional

- `bare_metal` (Boolean) Filter by bare metal hosts. When true, only bare-metal hosts are returned.
- `cloud_id` (Number) Filter by cloud ID. Only hosts in this cloud are returned.
- `compute_server_type` (String) Filter by compute server type code. Only hosts of this type are returned.
- `group_id` (Number) Filter by group ID. Only hosts in this group are returned.
- `phrase` (String) Filter by a search phrase matched against host names.

### Read-Only

- `hosts` (Attributes Set) The list of hosts matching the supplied filters. (see [below for nested schema](#nestedatt--hosts))

### Nested Schema for `hosts`

Read-Only:

- `bare_metal` (Boolean) Whether the host is a bare-metal host.
- `cloud_id` (Number) The ID of the cloud this host belongs to.
- `compute_server_type` (String) The code of the compute server type.
- `external_ip` (String) The external IP address of the host.
- `id` (Number) The ID of the host.
- `internal_ip` (String) The internal IP address of the host.
- `name` (String) The name of the host.
- `parent_host_id` (Number) The ID of the parent hypervisor host, if any.
- `power_state` (String) The power state of the host (e.g. on, off).
- `status` (String) The status of the host (e.g. provisioned, running).
