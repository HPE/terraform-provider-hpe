# hpe_morpheus_storage_volumes (Data Source)

Retrieves a list of Morpheus storage volumes, optionally filtered using one or more filter blocks.

## Example Usage

```terraform
# Filter by cloud name. Values are Go regular expressions; a storage volume
# matches the block if its cloud_name matches ANY value.
data "hpe_morpheus_storage_volumes" "by_cloud" {
  filter {
    name   = "cloud_name"
    values = ["Production"]
  }
}

# Filter by status.
data "hpe_morpheus_storage_volumes" "online" {
  filter {
    name   = "status"
    values = ["provisioned"]
  }
}

# Filter by the storage server the volume is provisioned on, by name.
data "hpe_morpheus_storage_volumes" "alletra" {
  filter {
    name   = "storage_server_name"
    values = ["^alletra-"]
  }
}

# Multiple filter blocks are ANDed together.
data "hpe_morpheus_storage_volumes" "prod_provisioned" {
  filter {
    name   = "cloud_name"
    values = ["Production"]
  }

  filter {
    name   = "status"
    values = ["provisioned"]
  }
}

# No filter blocks returns all storage volumes (up to 250).
data "hpe_morpheus_storage_volumes" "all" {}

# Consume the full objects returned in `storage_volumes`.
output "storage_volume_ids" {
  value = [for v in data.hpe_morpheus_storage_volumes.by_cloud.storage_volumes : v.id]
}
```

## Supported `filter` keys

Each `filter` block sets `name` to one of the keys below and `values` to one or
more Go regular expressions. A storage volume matches a block when the key's
value matches **any** of the supplied `values`; multiple `filter` blocks are
**ANDed** together.

| Key | Matches |
|-----|---------|
| `name` | The storage volume name. |
| `type_id` | The storage volume type id. |
| `type_code` | The storage volume type code. |
| `datastore_id` | The datastore id associated with the volume. |
| `datastore_name` | The datastore name associated with the volume. |
| `cloud_id` | The cloud (zone) id the volume belongs to. |
| `cloud_name` | The cloud (zone) name the volume belongs to. |
| `storage_server_id` | The storage server id the volume is provisioned on. |
| `storage_server_name` | The storage server name the volume is provisioned on. |
| `status` | The current status of the volume. |
| `uuid` | The UUID of the volume. |
| `provision_type` | The provisioning type of the volume. |
| `ref_type` | The reference type. |
| `ref_id` | The reference id. |
| `pool_name` | The storage pool name. |
