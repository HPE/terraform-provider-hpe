# hpe_morpheus_load_balancer_virtual_server (Data Source)

Looks up a load balancer virtual server by ID or VIP name within a given load balancer. This is useful for referencing existing virtual servers in other resources without hard-coding IDs.

## Example Usage

### Lookup by ID

```terraform
data "hpe_morpheus_load_balancer_virtual_server" "example" {
  id               = 99
  load_balancer_id = 1
}
```

### Lookup by VIP Name

```terraform
data "hpe_morpheus_load_balancer_virtual_server" "example" {
  vip_name         = "Example virtual server"
  load_balancer_id = 1
}
```
