# hpe_morpheus_load_balancer_virtual_server (Data Source)

Reads a Morpheus load balancer virtual server. This data source can be used to look up an existing virtual server by ID or VIP name to reference its attributes in other resources.

The `config` attribute contains the full configuration object returned by the API, which varies by load balancer type (e.g. NSX-T includes `applicationProfile`, `persistence`, `persistenceProfile`, `sslClientProfile`, `sslServerProfile`, and `pool`).

## Example Usage

### Look up by ID

```terraform
data "hpe_morpheus_load_balancer_virtual_server" "example" {
  load_balancer_id = 1
  id               = 99
}
```

### Look up by VIP Name

```terraform
data "hpe_morpheus_load_balancer_virtual_server" "example" {
  load_balancer_id = 1
  vip_name         = "my-web-vs"
}
```
